# 🤖 智能周报生成器

一个基于 Deno 开发的AI驱动智能周报生成工具，让工作汇报变得简单高效。

## ✨ 核心特性

### 🧠 智能分析
- **自然语言理解** - 支持自由描述工作内容，AI自动识别和分类
- **智能提取** - 自动提取时间、成果、问题等关键信息
- **语义分析** - 理解工作类型和重要性，智能排序

### 🎨 美观界面
- **现代化设计** - 渐变背景、动画效果、响应式布局
- **智能提示** - 实时输入提示和操作指导
- **模板支持** - 提供多种职业模板，一键填充

### 📊 专业输出
- **结构化格式** - 按照职场标准生成周报
- **重点突出** - 自动识别并强调关键成果
- **风险包装** - 将问题转化为体现个人价值的描述

## 🚀 快速开始

### 本地运行

```bash
# 安装 Deno
curl -fsSL https://deno.land/install.sh | sh
export PATH="$HOME/.deno/bin:$PATH"

# 运行项目
deno task dev
```

访问 http://localhost:8000 即可使用。

### 部署到 Deno Deploy

1. 将代码推送到 GitHub 仓库
2. 访问 [Deno Deploy Dashboard](https://dash.deno.com/)
3. 选择你的 GitHub 仓库
4. 设置入口文件为 `main.ts`
5. 点击部署
